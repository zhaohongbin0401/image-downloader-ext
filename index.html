图片下载助手

一键抓取当前网页全部图片 · 浏览器扩展（Edge / Chrome 通用）

Manifest V3 · 免费 · 开源

功能特性

自动扫描识别 img / source / 背景图 / 懒加载属性
实时预览弹窗内缩略图网格，点击勾选
批量下载一键将选中图片保存到本地
极速响应不依赖云端，纯本地运行

安装方法（开发者模式）

  1. 从仓库下载 image-downloader-ext 文件夹（或克隆后取该目录）
  2. 浏览器地址栏输入 edge://extensions（Chrome 则是 chrome://extensions）
  3. 右上角打开 开发者模式
  4. 点击 加载解压缩的扩展，选择 image-downloader-ext 文件夹
  5. 固定扩展图标到工具栏，访问任意网页后点击即可使用
